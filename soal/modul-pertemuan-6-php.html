A · Konsep dasar

Pemrosesan sekuensial itu apa?

Pemrosesan sekuensial adalah cara mengolah data secara berurutan. Program menerima satu data, melakukan proses yang sama, lalu berpindah ke data berikutnya.

INPUT
data masuk
→
PROSES
olah satu per satu
→
OUTPUT
hasil akhir
Inti pola: pada setiap putaran, program mengerjakan satu data dengan aturan yang sama. Data sebelumnya diringkas ke dalam variabel seperti $total, $jumlah, atau $terbesar.
Contoh kehidupan sehari-hari

Menghitung nilai kelas

  1. Ambil nilai mahasiswa pertama.
  2. Tambahkan nilai ke total dan naikkan penghitung.
  3. Ulangi untuk nilai berikutnya.
  4. Ketika data selesai, hitung dan tampilkan rata-rata.
Tiga pertanyaan kunci

Sebelum menulis kode

  1. Berapa banyak data yang akan masuk?
  2. Variabel apa yang harus diperbarui di tiap putaran?
  3. Apa kondisi yang membuat proses berhenti?
B · Tanpa MARK

Jumlah data sudah diketahui: gunakan for

Program mengetahui jumlah pengulangan sejak awal, misalnya tepat 5 nilai atau sebanyak $jumlahData yang diberikan pengguna.

Pola umum

for ($i = 1; $i <= $jumlahData; $i++) {
    // input dan proses satu data
}

Variabel $i berperan sebagai penghitung putaran. Pada setiap akhir putaran, $i bertambah satu.

Contoh telusur singkat

PutaranInput$total setelah proses
17070
280150
390240

Jika jumlah data = 3, loop berhenti setelah putaran ketiga. Rata-rata = 240 / 3 = 80.

C · Dengan MARK

Jumlah data belum diketahui: gunakan while

MARK atau sentinel adalah nilai khusus yang menandai bahwa input selesai. MARK bukan data yang ikut dihitung.

Contoh MARK

Pilih tanda yang jelas

  • -1 untuk data angka yang tidak mungkin bernilai negatif.
  • "selesai" untuk input teks.
  • 0 hanya jika nilai 0 memang tidak valid sebagai data.
Perhatian: jangan memilih MARK yang mungkin merupakan data sah. Jika nilai ujian boleh -1, maka -1 bukan MARK yang aman.
Pola umum

Baca → cek → proses

$nilai = bacaInput();
while ($nilai != -1) {
    // proses nilai
    $nilai = bacaInput();
}

Input berikutnya harus dibaca lagi di dalam loop. Tanpa itu, nilai tidak berubah dan loop dapat berjalan selamanya.

Alur dengan MARK

Baca nilai
→
Apakah MARK?
→
Tidak: proses
↺
Ya: selesai

Kata “tidak” mengarah ke tubuh loop; kata “ya” langsung keluar dari loop. Inilah perbedaan penting antara data dan penanda akhir data.

Naik tingkat

Statistik tanpa array

Satu data masuk, beberapa ringkasan diperbarui. Ini memperkuat cara berpikir algoritmik sebelum belajar struktur data.

Total

Tambahkan setiap nilai ke total.

$total += $nilai;

Rata-rata

Hitung setelah semua data selesai.

$rata = $total / $jumlah;

Lulus / tidak

Gunakan kondisi pada setiap nilai.

if ($nilai >= 60) $lulus++;

Terbesar

Bandingkan nilai saat ini dengan nilai terbesar.

if ($nilai > $max) $max = $nilai;

Terkecil

Bandingkan nilai saat ini dengan nilai terkecil.

if ($nilai < $min) $min = $nilai;

Edge case

Pastikan jumlah data tidak nol sebelum membagi rata-rata.

if ($jumlah > 0) { ... }
D · Studi kasus dan latihan program

5 program PHP lengkap

Semua contoh dibuat sebagai file .php yang menerima input melalui form browser. Simpan masing-masing kode, jalankan dengan server PHP lokal, lalu coba prediksi hasilnya sebelum menekan tombol.

Program 1 · Total dan rata-rata dengan for
Form browser, jumlah data diketahui
<?php
// Program 1: form browser dengan for
$hasil = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $jumlahData = (int) ($_POST["jumlah_data"] ?? 0);
    $total = 0;

    if ($jumlahData < 1 || $jumlahData > 5) {
        $hasil = "Jumlah data harus antara 1 dan 5.";
    } else {
        for ($i = 1; $i <= $jumlahData; $i++) {
            // Nama input dibentuk dari nomor mahasiswa.
            $namaInput = "nilai" . $i;
            $nilai = (float) ($_POST[$namaInput] ?? 0);
            $total += $nilai;
        }

        $rataRata = $total / $jumlahData;
        $hasil = "Total nilai: $total\n";
        $hasil .= "Rata-rata: " . number_format($rataRata, 2);
    }
}
?>

Program 2 · Total dan rata-rata dengan MARK -1
Form browser, jumlah data belum diketahui
<?php
// Program 2: form browser dengan while dan MARK -1
$hasil = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // Array ini hanya menjadi jembatan untuk membaca input form.
    $data = explode(",", $_POST["nilai"] ?? "");
    $total = 0;
    $jumlah = 0;
    $i = 0;

    while ($i < count($data)) {
        $nilai = (float) trim($data[$i]);

        if ($nilai == -1) {
            break; // MARK tidak ikut diproses.
        }

        $total += $nilai;
        $jumlah++;
        $i++;
    }

    if ($jumlah > 0) {
        $rataRata = $total / $jumlah;
        $hasil = "Jumlah data: $jumlah\n";
        $hasil .= "Total nilai: $total\n";
        $hasil .= "Rata-rata: " . number_format($rataRata, 2);
    } else {
        $hasil = "Tidak ada nilai sebelum MARK -1.";
    }
}
?>

Program 3 · Mencari nilai terbesar dan terkecil
Form browser, inisialisasi dari data pertama
<?php
// Program 3: mencari nilai terbesar dan terkecil di browser
$hasil = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $data = explode(",", $_POST["nilai"] ?? "");
    $i = 0;
    $jumlah = 0;
    $terbesar = null;
    $terkecil = null;

    while ($i < count($data)) {
        $nilai = (float) trim($data[$i]);

        if ($nilai == -1) {
            break;
        }

        // Data pertama menjadi pembanding awal.
        if ($terbesar === null || $nilai > $terbesar) {
            $terbesar = $nilai;
        }
        if ($terkecil === null || $nilai < $terkecil) {
            $terkecil = $nilai;
        }

        $jumlah++;
        $i++;
    }

    if ($jumlah > 0) {
        $hasil = "Jumlah data: $jumlah\n";
        $hasil .= "Nilai terbesar: $terbesar\n";
        $hasil .= "Nilai terkecil: $terkecil";
    } else {
        $hasil = "Tidak ada data sebelum MARK -1.";
    }
}
?>

Program 4 · Menghitung lulus dan tidak lulus
Form browser, seleksi di dalam while
<?php
// Program 4: menghitung jumlah lulus dan tidak lulus
$hasil = "";

Program 5 · Rekap lengkap satu kali jalan
Form browser: total, rata-rata, min, max, lulus, tidak lulus
<?php
// Program 5: rekap lengkap nilai dari form browser
$hasil = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $data = explode(",", $_POST["nilai"] ?? "");
    $total = 0;
    $jumlah = 0;
    $lulus = 0;
    $tidakLulus = 0;
    $terbesar = null;
    $terkecil = null;
    $i = 0;

    while ($i < count($data)) {
        $nilai = (float) trim($data[$i]);

        if ($nilai == -1) {
            break;
        }

        $total += $nilai;
        $jumlah++;

        if ($nilai >= 60) {
            $lulus++;
        } else {
            $tidakLulus++;
        }

        if ($terbesar === null || $nilai > $terbesar) {
            $terbesar = $nilai;
        }
        if ($terkecil === null || $nilai < $terkecil) {
            $terkecil = $nilai;
        }

        $i++;
    }

    if ($jumlah > 0) {
        $rataRata = $total / $jumlah;
        $persenLulus = ($lulus / $jumlah) * 100;
        $hasil = "Jumlah data: $jumlah\n";
        $hasil .= "Total nilai: $total\n";
        $hasil .= "Rata-rata: " . number_format($rataRata, 2) . "\n";
        $hasil .= "Nilai terbesar: $terbesar\n";
        $hasil .= "Nilai terkecil: $terkecil\n";
        $hasil .= "Jumlah lulus: $lulus\n";
        $hasil .= "Jumlah tidak lulus: $tidakLulus\n";
        $hasil .= "Persentase lulus: " . number_format($persenLulus, 2) . "%";
    } else {
        $hasil = "Tidak ada data sebelum MARK -1.";
    }
}
?>

        <br>

Cara menjalankan program PHP di browser

  1. Simpan salah satu kode sebagai file, misalnya program1.php.
  2. Letakkan file di folder server PHP, misalnya folder htdocs pada XAMPP.
  3. Jalankan Apache, lalu buka http://localhost/program1.php di browser.
  4. Isi form. Untuk program dengan MARK, akhiri data dengan -1.
Catatan: file modul ini bisa dibuka langsung di browser sebagai bahan belajar. Contoh program PHP dijalankan melalui server PHP seperti XAMPP, Laragon, atau server lokal PHP karena browser tidak mengeksekusi PHP secara langsung.

Penutup

Kesimpulan

Pemrosesan sekuensial melatih kita mengolah data secara teratur: data masuk, diproses satu per satu, diperiksa kondisi berhentinya, lalu hasil ditampilkan. Saat jumlah data sudah diketahui, gunakan for. Saat jumlahnya belum diketahui, gunakan while dengan MARK yang tidak mungkin tertukar dengan data valid.

Dengan variabel akumulator, satu kali perjalanan melalui data sudah cukup untuk menghitung total, rata-rata, nilai terbesar, nilai terkecil, jumlah lulus, dan jumlah tidak lulus. Pastikan setiap variabel diinisialisasi, input berikutnya dibaca di dalam loop, MARK tidak ikut dihitung, dan pembagian nol ditangani.

Jembatan ke materi berikutnya: setelah pola “satu data setiap putaran” benar-benar dipahami, barulah array menjadi alat untuk menyimpan banyak data. Array bukan pengganti algoritma; ia hanya membantu menyimpan data yang algoritmanya sudah kita pahami.
Checklist sebelum mengumpulkan program
  • Apakah variabel sudah diberi nilai awal?
  • Apakah kondisi loop bisa menjadi salah?
  • Apakah MARK tidak ikut diproses?
  • Apakah rata-rata aman saat tidak ada data?
